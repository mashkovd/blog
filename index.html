01 · The problem

AI coding is the easy part.

The hard part is letting agents move work toward production without turning delivery into an opaque chat log.

01 / Context

Memory drifts

An agent can reason from yesterday’s PR head, stale CI or an old comment.

02 / Control

Approval disappears

“Looks good” in chat is not a durable workflow signal.

03 / Evidence

Done is ambiguous

Merge is not release, deployment, or observed production state.

DevLoop moves trust from conversation to artifacts.

04 · Boundary

Why hide the issue from the implementer?

Because “read everything and infer intent” is how agentic workflows become non-auditable.

Bad loop

Claude reads issue, comments, chat context and guesses what was meant.

Hard to audit. Easy to drift.

DevLoop

Claude implements the accepted proposal. If the contract is incomplete, it stops.

Clear boundary. Durable evidence.

If the proposal is incomplete, stopping is success.

08 · Review gate

The reviewer blocked real issues.

Claude did not just say LGTM. It found blocking P2s and named exact invariants.

P2

ADR heading invariant

Bare English headings could pass even when the bilingual heading rule was broken.

P2

Paired content drift

English and Russian project files could load independently and diverge.

P2

Tests not gated

The new test script existed, but CI/build did not execute it yet.

The gate blocks unresolved evidence, not vibes.

09 · What broke

The useful part is what failed.

The loop got better because failures were turned into rules future agents must follow.

#17

Lockfile platform trap

npm install pruned native optional dependencies; Docker/npm ci broke later.

Rule: regenerate lockfiles with --package-lock-only.

#19

Wrong storage rule

try/catch around localStorage made toggles inert when storage was blocked.

Rule: persistence may fail, function must not.

#29

Acceptance criterion deadlock

The implementer could not satisfy criteria that required text in PR body.

Rule: criteria must be satisfiable by a commit.

#21

False evidence row

A ledger copied both a wrong intervention row and its correction.

Fix the narrative, keep the mistake on record.
